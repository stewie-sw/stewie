# UltraBuild evidence package

**Source commit:** `608c6881e9be5754ac801a7833ee1f8217c238a0`
**Package version:** `0.1.0`
**Generation state:** clean tracked worktree on 2026-07-29; identity status

This directory retains the small reproducible outputs from the implemented persistent world-state
slice. SQLite authority databases and content-addressed raster bytes are regenerated by the commands
below and are intentionally not retained. `evaluation/trials.jsonl` is retained because it is the raw
input to the aggregate and descriptive statistical reports.

| Evidence | Command | Retained artifact | Support level |
|---|---|---|---|
| Minimal persistent graph | `stewie-ultrabuild demo --output <dir>` | `demo/demo-summary.json` | reproducible controlled demonstration |
| Multi-robot closed loop | `stewie-ultrabuild multi-demo --output <dir>` | `multi-robot/multi-robot-summary.json` | controlled synthetic demonstration |
| Conflict preservation | `stewie-ultrabuild conflict-demo --output <dir>` | `conflict/conflict-summary.json` | controlled synthetic demonstration |
| Baselines and ablations | `stewie-ultrabuild evaluate --output <dir>` | report plus 1,728 trial rows | exposed exploratory diagnostic |
| Perturbations | `stewie-ultrabuild perturb --output <dir>` | 84-cell report | exposed exploratory one-factor diagnostic |
| Fault injection | `stewie-ultrabuild fault-inject --output <dir>` | eight executable probes | controlled fault evidence |
| Performance | `stewie-ultrabuild benchmark --measured-runs 200 --output <dir>` | host manifest and partial-budget report | host-specific microbenchmark |

The evaluator uses eight synthetic terrain windows. Action type, seed, and method are repeated
measures; they are not additional independent terrain units. Its arrays and seeds were exposed during
development, so none of these results are confirmatory.

These artifacts do not establish physical fidelity, mission readiness, flight safety, novelty,
planetary generality, or superiority to existing mapping/world-model systems. External baselines,
physical robot trials, distributed partitions, and independent clean-room replication remain absent.
