# Data and asset provenance

**Artifact ID:** `ART-DATA-PROVENANCE`
**Producer node:** `INV-001`
**Consumers:** `EXP-010`, `VERT-010`, `EXP-020`, `EXP-030`, `DISS-010`
**Status:** inventory baseline; license and checksum closure remains open.

## Governing rule

No dataset, terrain product, robot model, calibration, paper-derived constant, generated scenario, or
visual asset enters a reported experiment without a source, acquisition/generation method, license or
use restriction, content hash, transformation lineage, resolution/frame/units, and responsible graph
node.

`docs/data_book.md`, `docs/map_reference.md`, `THIRD_PARTY.md`, `papers/CITATIONS.md`, and per-bundle
metadata are inputs to this registry, not substitutes for a frozen experiment manifest.

## Required experiment manifest fields

- canonical source citation and persistent identifier/URL;
- acquisition date and fetch tool/version;
- original and transformed SHA-256 digests;
- byte size/media type;
- license, attribution, redistribution, and access restrictions;
- CRS, datum, frame, axis order, units, bounds, resolution, no-data convention;
- transformation command, code commit, parameters, and input hashes;
- generated-versus-measured classification;
- calibration/assumption/unknown tags;
- train/pilot/evaluation role; and
- known defects or exclusions.

## License boundary

The repository root license is currently all-rights-reserved. Some NASA/USGS data may be public
domain or CC0; some derived or external products use other licenses. An existing benchmark text
promises an open release and an existing citation document calls the repository CC0; neither matches
the governing root license.

Until resolved, the reproducibility package may publish metadata, hashes, fetch instructions, and
originally authored outputs only to the extent authorized. It must not infer that an asset inherits
the repository license or that the repository inherits an asset’s license.
